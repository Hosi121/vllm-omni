The plan should target end-to-end execution and profiling for every feasible pairing, with a documented feasibility result for every remaining cell. We cannot promise every model fits every device: Qwen3.8-27B alone needs approximately 12.6 GiB for ideal four-bit language weights, before other weights, state, workspace and the OS.
Use the 60-cell audit as the backlog. Each cell progresses through artifact readiness → correctness → complete local execution → profiling → qualification.
1. Establish shared prerequisites
- Pin compatible Omni/vLLM/runtime builds. Resolve the CPU TTS version mismatch and native Windows CPU backend gap.
- Obtain complete, pinned MiniCPM-o 4.5 and InternVLA-A1 checkpoints.
- Define each device’s exact SKU, RAM, OS, drivers and power mode. Keep Windows and WSL results separate.
- Finish integrating all native and external stages into the shared memory admission ledger.
- Extend the existing stage boundary to support persistent backend sessions, explicit state lifetime, cancellation, backpressure and placement reporting.
- Add a common qualification runner that consumes the matrix and archives configuration, outputs, traces and failures.
Keep Omni’s orchestration and vLLM’s internal execution. Add model adapters and backend implementations without introducing another scheduler.

Mobile execution needs access to a device capable of running our complete application. Existing AI Hub jobs establish component evidence; they do not establish the local stateful loop, playback behaviour or sustained co-residency.

4. Profile every completed pipeline with the same protocol
Dimension	Measurements
Startup	Compile separately from process startup, model loading, first execution and warm restart. Record cache conditions.
Text	TTFT, inter-token latency, decode throughput, total completion; separate effective prefill from isolated compute.
Speech	First playable audio, real-time factor, chunk arrival intervals, playback underrun count/duration, interruption latency.
Multimodal / VLA	Preprocessing, encoder and downstream latency; observation-to-action age and deadline misses.
Memory	Loading and runtime peaks, weights, session state, workspace and transfer buffers; host RAM, WSL quota and discrete VRAM separately.
Placement	Actual executed devices, CPU fallback, copies, layout conversions, synchronisation and queue waits.
Power / thermal	Thirty-minute sustained runs, clocks, temperature and available energy measurements. Identify sensor scope; GPU power is not whole-device power.
Reliability	Slow consumer, cancellation, repeated sessions, memory pressure and worker failure; verify release and absence of duplicate or stale output.


Start at concurrency 1, then 2/4 where memory permits. Use short, medium and long workloads plus state-boundary cases. Collect at least 20 measured requests per steady-state configuration, retain raw samples, and report p50/p95 with sample counts. Run detailed tracing separately to quantify instrumentation overhead.
For heterogeneous pipelines, measure single-backend, split-serial and split-overlapped execution using identical inputs and quality settings. Component timings cannot substitute for these measurements.
5. Define release criteria before tuning
A pairing earns E2E qualification only when it has:
- A reproducible installation, pinned artifact and explicit execution plan.
- Complete declared input-to-output behaviour and model-specific quality checks.
- Correct streaming/state lifecycle and memory admission.
- Verified device placement and explicit fallback.
- Raw performance, memory and sustained-load reports.
Functional qualification and performance qualification should remain separate. Proposed real-time TTS acceptance includes RTF below 1 and no post-startup playback underruns; text latency and VLA deadlines need workload-specific targets rather than invented universal thresholds.
The first implementation batch should finish environment compatibility, the shared qualification runner and S25 Spark’s full local loop. Those establish the execution and measurement foundation for every subsequent matrix cell.
