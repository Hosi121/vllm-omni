# Spark-X2.5 attention layer on Snapdragon X Elite CRD

**One fixed-shape decoder attention layer from the real Spark-X2.5-1.7B checkpoint executed on the hosted Snapdragon X Elite CRD NPU (Windows 11 ARM64). This is component evidence, not complete Spark generation or a local Omni deployment.**

The [Galaxy S24 provenance record](../spark_s24_full_attention/README.md) pins the FP32 source ONNX, W8A16 QDQ ONNX, calibration and exact input fixture. Its QNN DLC compile job `jpe7z8l15` produced target model `mq9y70k0n`; the same DLC and fixture dataset `d7m83gjy2` were reused here without recompilation. [Inference submission](inference_submission.json) job `j5wl7876p` and [profile submission](profile_submission.json) job `jg9zmkmlp` both requested `--compute_unit npu` for the exact device. The [raw inference job](inference_report.json) and [raw profile job](profile_report.json) completed. Their service build, OS, chipset and target IDs are preserved in those reports.

The [three outputs](device_output.npz) were finite FP32 hidden/new-key/new-value tensors at a 1,024-token cache shape. They were bitwise identical to the earlier Galaxy S25 and S24 NPU outputs on the same fixture. The [audit](audit_report.json) measured hidden/key/value relative L2 of **1.351%/0.377%/0.650%** against original FP32 ONNX CPU, and **0.555%/0.0065%/0.0126%** against QDQ ONNX CPU. No next-token or task-level quality tolerance has been established.

All 73 execution-detail rows in the device profile were attributed to NPU. The 100 component inference-time samples had nearest-rank p50/p95 **1.433/1.606 ms** (minimum 1.346 ms). The service's `estimated_inference_time` was 1.346 ms, matching the minimum rather than the median. The reported component inference peak memory was 18,423,808 bytes. These are hosted component-job measurements; they exclude prefill, 27 other decoder layers, sampling, transfer, loading and a resident KV/ring/controller. Hardware, OS and hosted power state differ from the mobile runs, so these are not paired speed comparisons.

Re-audit with `benchmarks/edge_harness/experiments/audit_spark_qualcomm_attention.py` and the [pinned source artifact paths](../spark_s24_full_attention/README.md). `benchmarks/edge_harness/experiments/collect_aihub_component.py` retrieves the existing jobs using the local AI Hub client configuration. Neither script contains credentials.

**Matrix status: component NPU inference/profiled; NOT E2E.** Full qualification still needs an X Elite machine running the complete 28-layer Spark model through a resident Omni backend with prefill/decode/KV-ring/sampling, state and cancellation, token-quality checks, memory admission and sustained power/thermal measurements. Workbench is a test facility, not that deployment runtime.
