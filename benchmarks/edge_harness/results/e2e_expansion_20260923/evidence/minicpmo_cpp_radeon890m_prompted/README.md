# Radeon 890M MiniCPM-o: spoken visual question

This is one **standalone scoped complete** audio+image → text+speech request on native Windows 11 build 26200 with the pinned MiniCPM-o 4.5 Q4_K_M/F16 GGUF set. It uses the same [C++ runtime, patch and Radeon placement](../minicpmo_cpp_radeon890m/README.md) as the unprompted combined-input run. The image is a synthetic 448×448 red square. The question, “What color is the square in the image?”, was spoken by Windows SAPI's default `Microsoft Huihui Desktop` voice into [22,050 Hz PCM16](question_raw.wav), resampled to [16 kHz PCM16](fixture_0001.wav), and paired with the [JPEG](fixture_0001.jpg). Pinned CPU [Whisper tiny.en independently transcribed the input exactly](input_asr.json), WER 0; this verifies the acoustic fixture rather than relying only on the intended prompt text.

The [raw log](full.combined.log) records actual index-1 image and audio prefill. `GGML_VK_VISIBLE_DEVICES=1` selected the Radeon 890M; the runtime logged 37/37 language layers on `Vulkan0 (AMD Radeon(TM) 890M Graphics)`, vision on Vulkan0, TTS weights 0/21 GPU layers, and CPU Token2Wav/vocoder. The output was **“The square in the image is red.”** The [verifier report](full_report.json) pins ten weight hashes, executable/input hashes, text, all three contiguous nonzero 24 kHz [WAV chunks](round_000/tts_wav/), their 2.56 s [merged PCM](full_merged.wav), and the completion marker. Pinned [Whisper tiny.en transcribed the output exactly](output_asr.json), WER 0; this is an intelligibility proxy only.

One cold process took 18.63 s. [100 ms process sampling](full.profile.json) observed maximum RSS 15.57 GB and private bytes 15.44 GB, not proven loading peaks. The [same fixture on native Windows CPU](../minicpmo_cpp_windows_cpu_prompted/README.md) returned the same answer and all eight language token IDs; the [cross-device check](cpu_radeon_parity.json) verifies that the model and input hashes match. Speech PCM differs, so this is text/token parity, not waveform parity or a general numerical tolerance. It is one synthetic quality case, not a full image/audio suite, latency distribution, playable stream, memory admission or sustained-power result. No Omni stage binding or NPU execution is claimed.

To reproduce the fixture, use Windows `System.Speech.Synthesis.SpeechSynthesizer.SetOutputToWaveFile` with the stated sentence and default voice, resample mono audio to 16 kHz PCM16, and run the [same command](../minicpmo_cpp_radeon890m/README.md) with this directory's `fixture_0000.wav`, `fixture_0001.wav`, and `fixture_0001.jpg` as the `--test` prefix. The source and artifact hashes in [the report](full_report.json) are the definitive identity checks.
