# Spark-X2.5 full-attention layer on Galaxy S24 NPU

**One real Spark-X2.5-1.7B full-attention decoder layer ran on a hosted Samsung Galaxy S24 NPU; complete Spark generation did not.** This is a fixed decode-step component with a 1,024-token full-attention cache, not the 28-layer model, prefill, sampling, a resident KV/ring session or a device-local Omni controller. Qualcomm AI Hub Workbench provisions and releases a physical device for each component job; it is a test facility, not the deployment runtime. ADB still lists no attached device.

The source is the existing FP32 `spark_full_ctx1024.onnx` export from real Spark weights. Its SHA256 is `4e2b1c8d791b1ee0e9b75f3322a20a743c0bf8c40f9b98edd963f2944d6300bb` (205,618,089 bytes); downloading uploaded source model `mn14dw6zn` yielded the same byte-for-byte hash. Workbench [quantization job](quantization_provenance.json) `jg9zne6wp` used calibration dataset `d7x8e3d59` and produced QDQ ONNX source model `mmd5e3v3q`. Its downloaded external-data ZIP SHA256 is `703821ca8ace5672228919ea2add4901def4887748c381b12ffc8b259665c553`; the graph has 92 QuantizeLinear/92 DequantizeLinear nodes, INT8 weight zero-points and UINT16 activation zero-points (W8A16). The original and quantized graphs and the exact inference fixture are stored outside Git under `/home/zhout/project/edge_infer/models/`; the [audit](audit_report.json) pins their sizes and hashes.

The [compile job](compile_report.json) succeeded for exact device **Samsung Galaxy S24, Android 14**, using Workbench client `0.55.0`, service build recorded in the job JSON, target model `mq9y70k0n` and `--target_runtime qnn_dlc --quantize_io`. The old context-binary target was [rejected at submission](compile_legacy_option_rejection.json) by the current API; [Qualcomm's compile options](https://workbench.aihub.qualcomm.com/docs/hub/api.html) list `qnn_dlc` as a current target. The [inference job](inference_report.json) used the pinned dataset `d7m83gjy2` and requested `--compute_unit npu`; its three finite FP32 outputs are [retained](s24_output.npz). The [profile job](profile_report.json) also requested NPU and attributed all 73 execution-detail rows to NPU. Its 100 `all_inference_times` samples had nearest-rank p50/p95 **1,109/1,205 microseconds** (minimum 1,098 microseconds); the separate `estimated_inference_time` field equals the minimum and is not a median. Reported inference peak memory was 210,259,968 bytes. These are component-job figures; they exclude controller, transfers between stages, prefill, all other layers, sampling, loading and sustained heat.

The fixed fixture has FP32 input `[1,1,2048]`, cache tensors `[1,2,1024,256]`, rotary angles and mask. Local ONNX Runtime 1.29 CPU executions of the original FP32 source and downloaded QDQ source produced separate pinned outputs. Relative L2 errors for `hidden` / new key / new value were **1.236% / 0.376% / 0.651%** for QDQ CPU versus FP32 CPU, then **0.555% / 0.0065% / 0.0126%** for S24 NPU versus QDQ CPU. S24 and the prior S25 [NPU output](s25_output_prior.npz) matched exactly on the same dataset ([S25 inference provenance](s25_inference_prior.json), [S25 profile](s25_profile_prior.json)), although they used different compiled target formats and Android versions. These measurements suggest quantization contributes substantially to the source-to-device difference; they do **not** establish next-token or task-quality tolerance. The [audit report](audit_report.json) retains full precision metrics, cosines, artifact hashes, sample statistics and job IDs. The [audit script](../../../../experiments/audit_spark_qualcomm_attention.py) reproduces those comparisons with the downloaded artifacts and fixture.

The matrix remains **NOT E2E**. The next gate is a device-resident, complete Spark prefill/continuous-decode/KV-ring/sampling loop with explicit state lifecycle, numeric token-quality checks, 128-token generation across 512/1024 context transitions, cancellation, memory admission and sustained thermal/power profiling. Workbench component jobs cannot substitute for that local runtime.
